# qblox-scheduler-experiment-analysis
QBS experiment and analysis

Successor of [qblox-quantify-experiment-analysis](https://github.com/SssZKing/qblox-quantify-experiment-analysis), ported from quantify-scheduler to qblox-scheduler. See [MIGRATION_PLAN.md](MIGRATION_PLAN.md) for the package versions and the migration plan.

## Install

A standalone env `qbs_env` (Python 3.12, Windows lock); the lab PC `qblox_env` is not touched:

```
conda env create -f environment.yml
conda activate qbs_env
```
